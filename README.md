# GTA VI Fan Site

**Live demo:** https://gta6-site-omega.vercel.app/

An unofficial, fan-made 3D website for Grand Theft Auto VI.

## Features
- 3D rotating image ring with mouse parallax (React Three Fiber)
- Scroll animations and 3D tilt cards (Framer Motion)
- Clickable characters, vehicles and places with detail popups
- Live countdown to release and live Miami weather (Open-Meteo API)
- Responsive layout that works on mobile

## Tech Stack
React, Vite, Three.js, @react-three/fiber, @react-three/drei, Framer Motion

## Run Locally
    npm install
    npm run dev
